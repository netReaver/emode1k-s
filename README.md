# ✨ emode1k-s

### A little space for big plans 🌙

**emode1k-s** is a personal website for keeping goals, tasks, and learning-oriented content in one place. It was created as the author’s first project — with the idea of making plans easier to see, organize, and work through one step at a time. 🚀

> Turn “I’ll do this someday” into something you can actually start today.

## 🌱 What you can do

The site brings together personal planning and structured content. It’s designed to help you:

- keep track of goals and tasks;
- make plans feel more manageable by focusing on clear next steps;
- explore content organized around topics and learning materials;
- return to your plans and keep moving forward at your own pace.

The exact subjects and learning materials depend on the content published on the site. **emode1k-s isn’t presented as a fixed course**; it’s a place where goals, tasks, and knowledge content can live together.

## 🎨 Design

The interface uses a **dark, GitHub-inspired palette** with monochrome colors and subtle neon-white accents. The goal is to keep the experience focused and easy on the eyes, while giving buttons, links, and interactive details a little glow. ⚡

## 🧩 How it works

The project combines a browser-based interface with database-related functionality:

- **HTML** provides the page structure.
- **CSS** controls the visual design and theme.
- **JavaScript** powers the client-side interactions.
- **PL/pgSQL** is used for database-side logic and migrations.

The database layer includes support for structured content and an audit log. Changes to selected content can be recorded and reviewed by administrators.

## 🛠️ Admin tools

Some features are intended for administrators rather than regular visitors. The repository includes an admin reports area with an audit history, including pagination and filters. Access is role-based, with checks performed on the backend as well as in the interface. 🔐

## 📚 What you can learn

As a visitor, the site can help you practice:

- setting and organizing personal goals;
- breaking larger plans into smaller tasks;
- building a steady, self-directed learning routine;
- keeping track of what you want to work on next.

For developers, the project is also a hands-on example of working with **HTML, CSS, JavaScript, database migrations, role-based access, and audit logging**.
